你的任务不是做高保真视觉稿，不是做品牌设计，也不是做颜色、插画、动效方案。  
你的任务是：**把页面结构、信息层级、模块位置、交互入口画清楚**，让我可以拿去继续做产品讨论和前端开发。

## 一、输出目标

请基于我提供的 Kinloop PRD，输出一套低保真页面草图，重点是：

2. 模块布局

不要输出高保真 UI，不要输出品牌视觉，不要花大量篇幅谈颜色和装饰。

## 二、产品背景

产品名：Kinloop

产品定位：
一个面向“长辈 + 家人”的家庭关怀空间。

产品核心：
1. 长辈端：AI 常驻 + 底部大语音按钮 + 首页家人会话带
2. 家人端：以“今天”为首页的判断与行动工作台
3. 双端共享：回忆时间线
4. 家庭协作：Circle of Care + 家庭码 + 权限边界

技术阶段：
1. 先做 Web MVP
2. 本地数据库 + 本地 API
3. AI 接口先占位

## 三、你必须遵守的设计约束

1. 长辈端首页不是聊天列表，不是摘要流。
2. 长辈端首页必须体现：
   - AI 常驻
   - 家人会话带
   - 底部固定大语音按钮
3. 家人会话带必须遵循：
   - 一人一框
   - 默认静止
   - 手动左右滑动
   - 闭环式浏览
   - 不自动轮播
4. 家人会话带卡片展示的是真实内容，不只是摘要。
5. 长辈端与家人端的聊天表现是不对称的：
   - 家人端像普通聊天流
   - 长辈端首页展示为会话带
   - 长辈点进后才进入具体会话页
6. 家人端默认首页必须是“今天”，不是聊天页。
7. 家人端底部导航固定为：
   - 今天
   - 聊天
   - 回忆
   - 协作
8. 长辈端底部导航固定为：
   - 陪伴
   - 联络
   - 回忆
   - 求助
