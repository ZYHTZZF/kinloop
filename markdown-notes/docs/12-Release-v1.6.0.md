# 知页 v1.6.0 · AI聊天笔记助手

- **聊天式AI助手**：多轮对话、当前笔记总结、答疑、润色和生成笔记。
- **基础Agent操作**：模型可提出修改正文／创建笔记，先预览，再由用户应用或放弃；原草稿、修订和容量检查继续生效。
- **自带API Key**：配置OpenAI兼容地址、模型及上下文预算；密钥经系统加密，仅存本机，不进入笔记备份。
- **上下文管理**：最新笔记快照、近期历史、早期目标与约束摘录、相关片段选择；不完整上下文禁用全文替换，显示压缩和估算信息。
- 支持停止生成、120秒超时与安全错误提示。现有编辑、模板、收藏、公式、PDF、备份恢复继续保留。

从“知识库设置 → AI设置”配置服务，再打开顶栏“AI助手”。Agent需要服务支持Tools，不支持时可关闭操作选项，仅聊天。模型、额度和实际窗口以服务商为准；新功能未内置商业密钥。

本轮验证使用本地模拟模型接口，未使用真实商业密钥请求外部模型。完整检查为55项核心、21项桌面流程、10轮退出诊断及实际Windows成品验证。AI内容需人工核实；token预算为估算值。

Windows x64成品解压后运行“知页.exe”，保留完整目录。源码与测试记录包、SHA256校验文件随版本提供。业务备份仍为格式2，兼容读格式1；AI配置与聊天记录不随业务备份迁移。
