# Mark It Down v1.6.1 · 右侧持续聊天与文件消息

- AI助手改为最右侧面板，可边编辑边聊天。收起后保留对话、输入草稿、活动附件与在途请求；切换笔记继续同一会话，旧建议不会覆盖已经变化的原文。
- 拖入`.md`／`.markdown`可批量导入笔记，也可使用列表标题旁导入按钮；同名自动编号、原笔记保留、失败整批回滚。
- 聊天支持图片、PDF、Markdown／TXT／CSV／JSON附件，支持拖放、选文件与粘贴图片。活动附件随后续消息继续发送，移除后停止附带。
- PDF默认在本地提取文字，提高兼容性；可切换原文件发送，需服务／模型支持。扫描PDF可转成图片；不将提取的文字冒充图表或扫描识别。
- 保留API系统加密、上下文预算、节选时禁用全文替换、预览后应用与自动保存保护。个人配置、密钥及聊天附件不随源码／业务备份分发。

少量真实合成资料请求验证：连接、图片及PDF文字模式通过，当前服务不接受PDF原文件模式。未发送真实笔记，未公开API配置。完整验证与限制见源码内测试记录。

Windows x64成品解压后双击 **Mark It Down.exe**，保留完整目录。升级继续使用原个人资料位置，退出软件后聊天会话清空。源码测试包及SHA-256校验文件随版本提供。
